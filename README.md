## About

I build software with a strong focus on real operational problems: clear data flows, maintainable architecture, access control, auditability and user interfaces that make daily work easier.

My current portfolio highlight is a school finance management system built from the ground up with a production-oriented stack.

## Featured Project

### School Finance Manager

A full-stack school management and finance platform designed to support:

- student and guardian records;
- receivables, payables and delinquency tracking;
- batch tuition generation with duplicate protection;
- financial dashboard with monthly comparison;
- permission-based access control;
- audit logging;
- XLSX/PDF reports.

Repository: [school-finance-manager](https://github.com/GustavoNicoletti/school-finance-manager)
